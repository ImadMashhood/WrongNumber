# Asset provenance

The dispatch room, supporting rooms, furniture, equipment, arched windows, and close exterior facades are procedural low-poly meshes. The 128-pixel repeating brick and floor patterns are generated in Rust; no new external room art or textures are required. The supplied reference image informs layout and silhouettes.

## Imported coastal map starter

Source: user-provided `Wrong_Number_Road_Map_Starter.zip`, supplied on October 27, 2026.

- `city/map.png`: the package's original `source_map.png`, copied without image edits; used as the M2 map background.
- `city/road_graph.json`, `addresses.json`, and `corrections.json`: imported data, compacted as JSON without changing values.
- `city/city_config.json`: original metadata, with the stale source-image path replaced by the repository-relative path.
- `city/import_report.json`: initial audit summary. The raw graph remains a draft; M2 uses actual routes within its connected pilot district.
- `tools/maps/build_city.py` and `STARTER_README.md`: supplied tracing script and source documentation, preserved for future editing. The tracing script was not executed during import.

Names, addresses, 4 km scale, and station positions remain provisional. The import contains 694 disconnected weak components, so route connectivity and geometry need review. The larger original archive, overlay, road mask, CSV, and GeoJSON remain available in the supplied ZIP.

For future external art/audio, record source, author, license, and required attribution here and retain supplied license files.

## Original telephone sound

`audio/telephone.wav` is generated by `tools/docs/build_ring.py` from two sine tones and an authored ringing envelope. It contains no third-party recordings.

`city/gameplay_config.json` records provisional pilot HQ/call node choices and gameplay tuning. The importer only normalizes declared node/road endpoint offsets up to one pixel per axis; raw imported files are preserved.

## Original structure boom and authored gameplay rules

`audio/structure-boom.wav` is generated by `tools/docs/build_explosion.py` from seeded noise and a decaying low-frequency tone; it contains no external recording. `scenarios/m3_rules.json` supplies the authored incident profiles, bounded escalation policy and solo director limits.

## Desktop font and caller illustrations

fonts/DesktopSans.ttf is the unmodified Liberation Sans Regular font supplied by the system liberation-sans-fonts package, distributed under the SIL Open Font License 1.1. Copyright and license are retained in fonts/LICENSE.txt. Its filename is an application asset alias; the font's internal family/name data is unchanged.

callers/00.png through callers/49.png are original procedural low-poly avatar illustrations. They contain no third-party photographs.

The 50 original caller illustrations are reproducible with tools/content/build_portraits.py (Pillow). The cast data and readable bible are generated from tools/content/callers.txt by tools/content/build_callers.py. Parody identities/biographies are fictional and do not depict or make claims about the referenced public figures.
